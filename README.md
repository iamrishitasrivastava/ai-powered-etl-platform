# AI-Powered Intelligent ETL Platform

## Overview
This project is an AI-powered ETL platform built using Python, Pandas, and Streamlit.

## Features
- CSV ingestion
- Duplicate removal
- Missing value handling
- Parquet conversion
- Streamlit dashboard

## Technologies Used
- Python
- Pandas
- PyArrow
- Streamlit

## Run the Project

Install dependencies:
pip install -r requirements.txt

Run Streamlit app:
python -m streamlit run app.py
