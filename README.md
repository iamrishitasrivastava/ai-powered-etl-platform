# AI-Powered Intelligent ETL Platform

## Overview
This project is an AI-powered ETL platform built using Python, Pandas, and Streamlit.

## Features
- CSV ingestion
- Duplicate removal
- Missing value handling
- Parquet conversion
- Streamlit dashboard
- CSV Upload
- Data Cleaning
- Duplicate Removal
- Missing Value Handling
- Department Filtering
- Employee Search
- KPI Metrics
- Interactive Charts
- Download Cleaned CSV
- Parquet Conversion
- Streamlit Dashboard

## Run the Project

Install dependencies:
pip install -r requirements.txt

Run Streamlit app:
python -m streamlit run app.py
